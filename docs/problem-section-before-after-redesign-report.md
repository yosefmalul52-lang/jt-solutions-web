# שדרוג סקשן הבעיה — Before / After + Lead Orbit

סקשן: `#problem` ("רוב העסקים לא נופלים בגלל שאין להם אתר...")
קבצים: `components/sections/ProblemSection.tsx`, `lib/home-funnel.ts` (`problemSection`), `app/globals.css` (`.prob-*`).

## 1. מה היה חלש לפני
- שני כרטיסים שטוחים בלבד (לפני / אחרי) בלי מרכז מחבר.
- אין תחושת מערכת או Lead Orbit.
- כותרת ארוכה בשורה אחת, בלי הדגשת "קמפיין".
- 4 פריטים בלבד בכל צד, עיצוב בסיסי (`home-ba-panel`).
- אין קווים מחברים, אין עומק ויזואלי פרימיום.

## 2. מה שונה ב־layout
- **3 עמודות בדסקטופ (RTL):** Before (ימין) → Lead Orbit (מרכז) → After (שמאל).
- **מובייל:** Before → חץ אנכי → Orbit → חץ אנכי → After.
- `max-w-6xl`, `section-shell`, `home-section--alt` — כמו שאר הדף.
- רקע ambient עדין (orb אדום רך + ירוק רך).

## 3. Before / After
**Before (אדום עדין):**
- Badge "לפני", כותרת + תת־כותרת.
- 5 פריטים: ליד נשכח, אין מדידה, אין מעקב, כמה ספקים, לא ברור מה עובד.
- רקע לבן + gradient `#FEF2F2`, border `#FECACA`, נקודות אדומות.

**After (תכלת/ירוק עדין):**
- Badge "אחרי", כותרת + תת־כותרת.
- 6 פריטים כולל **קמפיין נמדד**, ליד נכנס, מקור פנייה ברור, CRM / וואטסאפ, תזכורת חזרה, מעקב מסודר.
- רקע לבן + gradient `#ECFEFF` / `#ECFDF5`, border ירוק עדין.

## 4. Lead Orbit
כרטיס מרכזי `prob-orbit`:
- כותרת: **Lead Orbit**
- זרימה: **קמפיין → אתר → ליד → CRM → מעקב**
- 5 נקודות צבעוניות עם תוויות קטנות + קו gradient
- משפט: "כל חלק יודע להעביר את הפנייה לשלב הבא."
- border סגול/תכלת, gradient corner עדין.

## 5. קמפיינים
- בכותרת H2 שורה שנייה: "קמפיין, אתר, פנייה ומעקב".
- ב־Lead Orbit flow ובנקודות הצבע.
- בפריט After: "קמפיין נמדד".
- ללא הבטחות תוצאה — רק מדידה, חיבור ומעקב.

## 6. אנימציות
- Header: `SectionHeader` / `PremiumReveal` (fade up).
- Before: כניסה מימין (`x: 36`).
- After: כניסה משמאל (`x: -36`).
- Orbit: scale + fade, delay 0.18s אחרי הפאנלים.
- קווים (דסקטופ): gradient אדום→תכלת→ירוק, משיכה עדינה + נקודה מרכזית pulse.
- Hover על פריטים: highlight עדין.
- `prefers-reduced-motion`: ללא תנועה, הכל סטטי וגלוי.

## 7. מובייל
- עמודה אחת, ללא horizontal scroll.
- חצים אנכיים פשוטים בין החלקים (במקום קווים מורכבים).
- טקסטים בגודל קריא (0.8125rem+), כרטיס Orbit ממורכז.

## 8. Lint
עבר — 0 errors (2 warnings קיימים לא קשורים).

`npm run build` עבר בהצלחה.
