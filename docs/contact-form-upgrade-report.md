## 1. מה שינית

### עמוד יצירת קשר (`/contact`)

| שדה | תוכן |
|-----|------|
| כותרת | בוא נבין מה חסר בתשתית הדיגיטלית של העסק שלך |
| תת־כותרת | נבדוק איפה העסק נמצא היום, מה מונע מהפניות להגיע או להסתדר, ומה הצעד הכי נכון להמשך |
| Metadata | הוסר «סוכנות דיגיטל» — ממוקד «אבחון דיגיטלי» |

### טופס לידים (כל האתר)

**שדות חובה:**
- שם מלא
- טלפון
- מה הכי דחוף לך כרגע? (6 אפשרויות לפי האסטרטגיה)

**שדות אופציונליים:**
- אימייל
- הודעה

**הוסר מהטופס:**
- שירות מבוקש (רשימת שירותים טכנית)
- מתי להתחיל?
- תקציב משוער

**CTA:** קבל אבחון דיגיטלי חינם  
**Microcopy:** נחזור אליך עד 24 שעות. בלי התחייבות ובלי ספאם.  
*(נשמר — כבר מופיע בעמוד About ובאסטרטגיה כמענה בימי עסקים)*

**Placeholder הודעה:** ספר בקצרה מה אתה רוצה לשפר בעסק

### UX

| שיפור | פירוט |
|--------|--------|
| טופס קצר | 5 שדות במקום 7 |
| כפתור לא חסום | `disabled` רק בזמן שליחה — לא עד שכל השדות valid |
| Validation | `mode: onSubmit` + revalidate on change; הודעות שגיאה עם `role="alert"` |
| מובייל | `min-h-[44px]` לשדות, `inputMode` לטלפון ואימייל |
| פחות עומס טקסט | הוסרו בולטים מיותרים מסרגל הצד בעמוד contact |

### מנגנון שליחה — נשמר

| רכיב | שינוי |
|------|--------|
| `POST /api/contact` | אותו endpoint — Zod `contactApiSchema` |
| שדה API `service` | **נשמר** — מאחסן את בחירת הדחיפות (תאימות n8n webhook) |
| SMTP + n8n | ללא שינוי בזרימה |
| Prefill `?service=` | עודכן למיפוי לאפשרויות דחיפות חדשות |
| אנליטיקס | `lead_form_*` events — `service` = דחיפות שנבחרה |

### מסך הצלחה

«קיבלנו את הפנייה» + «נחזור אליך עד 24 שעות עם כיוון ראשוני — מה חסר היום ומה כדאי לבנות קודם.»

### אימייל נכנס

- תווית «מה הכי דחוף» במקום «שירות מבוקש»
- הוסרו שורות תקציב ולוח זמנים
- `replyTo` רק כשיש אימייל
